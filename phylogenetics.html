CORE IDEA

A phylogenetic tree is an inference, not a literal map of evolution.

نتیجه به توالی‌ها، هم‌ترازی، مدل و روش وابسته است؛ پس عدم‌قطعیت را هم در تفسیر بیاور.

Input

Comparable sequences

The biological question determines which sequences belong in the analysis. Distinguish carefully between orthologs, paralogs, and other homologous sequences.

Model

Alignment + evolutionary assumptions

Alignment quality and model assumptions affect the inferred topology, support values, and branch-length estimates.

Interpretation

Topology + support + context

Read topology, branch lengths, support values, rooting, taxonomic context, and biological knowledge together.

MAIN WORKFLOW

Build the analysis step by step.

Each stage answers a different research question. Tree construction should be treated as an analysis pipeline, not a one-click result.

01 Sequence selection

Define the biological comparison

Start with the biological question, not with tree-building software. Decide which organisms, genes, proteins, or homologous groups should be compared.

NCBI UniProt BLAST
Check: accession IDs, organism, sequence type, homology, orthology/paralogy, redundancy
02 Quality control

Check whether the sequence set is suitable

Inspect sequence length, ambiguity, missing regions, redundancy, unusual sequences, and biological comparability before alignment.

Length Comparable?
Quality Ambiguities?
Redundancy Overrepresented?
03 Alignment

Build a multiple sequence alignment

Align homologous sequences so that biologically comparable positions can be evaluated across the dataset.

MAFFT Clustal Omega
Important: Poor alignment can propagate uncertainty or error into tree inference.
04 Tree inference

Choose an inference method and model

Different methods use different assumptions. The method and evolutionary model should match the research question, sequence type, and dataset.

Neighbor-Joining Distance-based
Maximum Likelihood Model-based
Bayesian Posterior inference
05 Support

Evaluate support and uncertainty

Use an appropriate support procedure and report exactly what the reported value represents.

Bootstrap

Assesses how consistently a grouping is recovered under the chosen resampling procedure.

Posterior probability

A model-based posterior quantity. It has a different interpretation from bootstrap support.

06 Interpretation

Interpret the tree in biological context

Separate what the tree directly shows from the biological explanation you infer from it.

Topology Which sequences cluster?
Support How stable is the inferred grouping?
Branch length What quantity does it represent?
Rooting How was evolutionary direction assigned?
HOW TO READ THE TREE

Read the topology, branches, root, and support separately.

These elements answer different questions and should not be treated as interchangeable.

01

Topology

The branching pattern describes the inferred pattern of relatedness among the included taxa or sequences. Rotating branches around a node does not change the topology.

02

Branch length

طول شاخه معمولاً تغییر ژنتیکی تخمینی (substitution به ازای هر site) است، نه الزاماً زمان.

03

Rooting

Rooting adds direction to an otherwise unrooted topology. Outgroup rooting is a common approach, while midpoint rooting relies on additional assumptions.

04

Support

Support values describe how strongly a particular relationship is supported under the selected procedure. Their meaning depends on the support method.

05

MRCA

For a rooted tree, the most recent common ancestor helps describe relative patterns of relatedness. This interpretation depends on the quality and rooting of the inferred tree.

06

Biological meaning

A tree can support a relationship hypothesis under specific assumptions, but it does not independently establish every biological explanation.

EVIDENCE CHECK

Keep the inference chain visible.

A strong phylogenetic workflow makes it clear which information comes from the sequence records, which result is computationally inferred, and which conclusion is biological interpretation.

Curated / Database

Sequence identity and metadata

Accession records, organism information, annotations, sequence provenance, and other metadata define the input dataset.

Computational

Alignment and tree inference

The alignment, evolutionary model, inference method, and support procedure determine the computational result.

Biological interpretation

Evolutionary hypothesis

The biological explanation should be interpreted in light of the dataset, model, support, rooting, taxonomy, and existing biological knowledge.

COMMON MISTAKES

Where phylogenetic analyses commonly go wrong.

Most interpretation errors happen before or after the tree is built.

01

Choosing sequences by name alone

Similar names do not guarantee the correct biological comparison. Verify accession, organism, gene/protein identity, and homology.

02

Mixing orthologs and paralogs without a question

Different homolog relationships can answer different biological questions. Sequence selection should follow the intended comparison.

03

Ignoring alignment quality

Poorly aligned or biologically non-comparable regions can affect downstream tree inference.

04

Treating bootstrap as probability

Bootstrap support reflects stability under a chosen resampling procedure. It is not simply the probability that a clade is true.

05

Confusing branch length with time

Branch lengths often represent estimated genetic change, such as substitutions per site, rather than elapsed evolutionary time.

06

Ignoring rooting

An unrooted topology does not automatically provide a direction of evolutionary history. Rooting should be justified.

07

Overinterpreting support values

Support values must be interpreted according to the method that generated them. Bootstrap and posterior probability are not interchangeable.

08

Overinterpreting the tree

A tree supports specific relationship hypotheses under specific assumptions. It does not independently establish every biological explanation.
